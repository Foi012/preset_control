# 生鱼片工具箱 · Sashimi Toolbox

A draggable floating toolbox for SillyTavern. One install, one trigger — pick a tool:

| 工具 | 做什么 |
| --- | --- |
| **预设控制台** | 把扁平的对话补全预设变成紧凑的开关面板：切换、分组、编辑、导入导出条目，且**不改动 prompt 顺序**。 |
| **连接档案** | 在 ST 自己的连接配置之上做一排**精选的一键切换**，补回切换时被丢掉的采样参数 / 附加参数，并修正「切换时部分正则被关掉」的问题。 |
| **聊天导出** | 把当前聊天或 `.jsonl` 聊天记录清洗后导出为 **TXT / EPUB** 电子书。 |

各工具相互独立，共用同一个浮动入口。


## 预设控制台

在快速面板里切换开关，在文本工作台里阅读、编辑和整理预设。分组只改变显示组织，不重排真实发送顺序。

- **快速开关与方案。** 一键应用保存的开关组合，也可继续单独调整。方案可以覆盖整套条目或选中的部分条目。
- **快速分组。** 单选／多选规则、最多三层嵌套；支持新建、移动和删除分组。条目名约定仍可提供初始分组与控件建议，不要求预设遵循特定标题格式。
- **文本工作台。** 连续阅读全部条目或发送文本，切换完整内容／摘要，搜索名称、原文、变量和展开内容。选择文字后可在侧栏编辑原文、查看变量来源、整理分组或管理方案。
- **变量来源。** 计算 `setvar/getvar/addvar` 及对应全局宏，追踪设置与追加来源；`{{char}}`、`{{user}}` 等保留原样。角色卡、世界书和聊天等显示占位块。此预览不包含完整模型请求的裁剪或第三方变换。
- **跨预设复制。** 对照来源与目标文本，选择完整条目，在目标正文中的位置粘贴，检查后保存。保留原生属性并生成新 ID，来源不变。
- **手机工作台。** 正文与详情分页面显示，复制时用箭头切换来源／目标；确认插入位置后再粘贴。手机实机兼容仍需验收。
- **保存保护。** 工作台正文、开关、分组和复制修改先保留在草稿中；方案另存／删除会独立立即保存。配置随预设携带，旧快照迁移为方案，保留原有开关范围。

功能与边界见 [FEATURES.md](src/features/preset-console/FEATURES.md)，本地测试与待验收项目见 [TESTING.md](TESTING.md)。

## 连接档案

ST 的连接配置（Connection Profiles）已经把端点 + 密钥 + 模型 + 预设打包成一个「档案」，但下拉列表会把全部档案都列出来，名字又长。连接档案在你常用的工具箱里做一层薄编排：

- **精选一键切换。** 把你高频 A/B 的几套「机位」固定成一排，点一下就切（底层调用 ST 自己的 `/profile`，安全的 url + 密钥 + 模型 + 预设切换仍由 ST 负责）。
- **补回被丢掉的参数。** ST 档案不带采样参数与附加参数；每套机位可绑定温度 / Top P / 惩罚 / 最大长度与「主体参数包含·排除·请求标头」，切换后自动重新写入（含对 `/profile` 尾随重载的容错重写）。
- **切换时保持正则开启。** ST 切换档案有时会把部分正则脚本（全局 / 角色 / 预设）悄悄关掉——开启此项后，切换会在重载完成后把切换前开启的正则重新打开（**只开不关**，可在面板里关闭）。
- **从不存密钥。** 只按 id 引用 ST 的档案，绝不保存密钥本身。

## 聊天导出

把一段聊天变成干净的电子书，是一个四步向导：

1. **来源** — 读取当前聊天，或拖入 / 导入 `.jsonl`；读取成功自动进入下一步。
2. **规则** — 扫描成对标签，设定**包含内容**（用户楼层 / 隐藏楼层、楼层范围、角色分隔线、正文与标题规则）与**排除内容**（think / OOC 等预设 + 自定义规则）。每个标签只能落在一个去向：不处理 / 排除 / 包含。
3. **预览** — 逐条对照原文与清理后的结果；正则有问题会**阻止导出**，不会生成空章节的坏文件。
4. **导出** — 设置书籍信息（标题 / 作者 / 语言、可选封面）、章节切分方式，导出 **TXT** 或 **EPUB**。

导出的 EPUB 已在 Apple Books 与 Calibre 中验证可正常打开。


## 安装

1. 在 SillyTavern 中打开 **Extensions**，点击 **Install Extension**。
2. 粘贴仓库地址：

   ```text
   https://github.com/Foi012/preset_control
   ```

3. 点击 **Install**，然后刷新 SillyTavern。
