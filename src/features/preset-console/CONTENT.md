# 界面文案规则

直接说明操作对象、结果和生效时间，避免让用户理解内部存储机制。

| 使用文案 | 含义 |
| --- | --- |
| 开启条目 | 打开条目；实际输出仍取决于触发条件和发送位置 |
| 未加入发送顺序 | 内容存在，但不在发送队列；开启会加入末尾 |
| 未分组 | 尚未归入用户分组 |
| 方案 | 保存的一套条目开启／关闭组合，不保存正文 |
| 另存方案 | 立即保存当前组合；其他未保存修改保留 |
| 应用方案 | 按方案范围调整开关，保留正文修改；工作台中仍须保存才生效 |
| 撤销全部未保存修改 | 撤销正文、开关、分组和复制修改，保留已保存方案 |
| 撤销这次粘贴 | 只移除最近一次复制加入的条目 |
| 锁定开启 | 不能在快速开关里关闭；可在快速分组设置中解除 |
| 执行此宏后的值 | 该次操作的结果；后续宏仍可能修改它 |

复制场景的提示必须点明目标预设。保存失败保留修改，不用成功通知覆盖错误。
宏表达式、变量名和条目名称是用户内容，保持原样；诊断用中文解释影响和可采取的操作。
