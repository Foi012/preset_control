# 预设控制台：当前功能与边界

更新：2026-10-21。本文描述当前实现，取代早期产品方案；实现细节见 [DESIGN.md](DESIGN.md)，验证状态见 [TESTING.md](../../../TESTING.md)。

## 核心流程

阅读文本 → 修改或试切开关 → 整理分组 → 检查发送文本 → 保存。

“预设”是 SillyTavern 的预设文件；“方案”仅保存条目开启／关闭的组合。“分组”组织条目并设置单选／多选规则，不改变请求顺序。用户不需要先建分组才能创建方案。

## 快速面板

- 快速开关：应用方案，操作条目、分组及文本输入；操作即时应用并沿用自动持久化。
- 快速分组：新建、重命名、删除、移动和嵌套分组，最多三层。删除自定义分组不删除正文；子组提升，相关配置引用清理。原生标题生成的分组可隐藏。
- 新建分组只提供单选／多选；保留历史复杂层级的兼容行为，不主动改写原有规则。
- 工作台入口使用设置旁的图标；方案下拉底部也可打开工作台的方案页。
- 旧模式布局与独立快照编辑界面已移除。

## 桌面文本工作台

正文是主要区域，侧栏按需出现，包含条目、分组、方案和复制四页。编辑与关联共用条目页，不再另外弹出分组对话框。

顶部是预设／方案选择、更多菜单、跨预设复制、保存、主题及关闭。文档行显示当前选择，提供查找和取消选择图标。阅读方式放在底部，用两组分段选择器控制：

| 阅读方式 | 呈现 |
| --- | --- |
| 全部条目 | 包括 OFF 和未加入发送顺序的条目，保留定义内容与可计算结果 |
| 发送文本 | 当前草稿中参与普通生成的预设文本、非预设占位块，以及无法定位内容的明确说明 |
| 完整内容／摘要 | 同一正文的显示密度；摘要仍保留占位块和逐项展开入口 |

点击条目或选择文字会打开编辑侧栏；整理选择与启用开关相互独立。搜索覆盖名称、原文、变量名和展开内容，并区分命中类型。

条目页固定三个区域：编辑、当前读取／写入的值、其他关联。来源名称是说明文字，查看原文是明确动作；同一关联条目去重，不重复铺开整份内容。修改保存原文与宏表达式，不把累计或展开结果覆盖回原文。

分组页复用树和编辑控件，支持新建、子组、删除、移动和分配选中条目。方案页上方提供另存方案和删除，列表可预览作用范围、ON/OFF 状态并应用。方案没有独立草稿层，也没有“更新当前方案／恢复当前方案”菜单。

## 方案与旧数据

- 整套方案记录创建时已放置、可切换、非系统占位条目的状态；局部方案只记录所选范围。OFF 状态也保存。
- 应用方案仅修改所记录的范围；后来新增条目保持自身状态。试切不会更新已保存方案。
- 另存／删除方案独立立即保存配置，不顺带提交尚未保存的正文、开关、分组或复制修改。失败时保留编辑内容并报告错误。
- 配置仍位于 `extensions.presetEasyToggle`，保留备份和损坏保护。
- 首次成功迁移保存时，将旧模式快照转换为独立方案，名称为“模式 / 快照”；原有每项 ON/OFF 与局部范围保持不变。无快照的模式不伪造方案。
- 旧类型和原始字段仅用于读取迁移与数据兼容，不恢复旧布局入口。

## 变量与发送文本

预览是隔离的纯计算，不调用生成接口，不执行真实变量写入。支持 `setvar/getvar/addvar` 和全局对应形式，按当前宏引擎设置处理替换顺序。数字相加、文字追加、数组追加分别呈现；读取值保留当时的贡献链，后续 set 重置当前来源。

OFF 条目不影响当前结果，候选内容可阅读和试用；同变量关系不自动等于互斥或必需依赖。未知或不能可靠计算的表达式保留原文并诊断。详见 [VARIABLES.md](VARIABLES.md)。

发送布局使用原生顺序、注入属性与聊天长度，显示角色卡、世界书、聊天等占位块；上下文宏保持字面形式。关闭的系统占位条目仍显示位置，并标注未开启、不发送。绝对注入条目无法定位时，明确列在“已开启，但未能放入发送位置”区域，不静默遗漏，也不假装有准确位置。

这里的发送文本是普通生成下的预设文本预览，不是完整请求复现：不模拟 token 裁剪、tools、第三方脚本或请求变换；非预设内容中的变量写入不会被自动执行。缺少聊天上下文时仍可阅读、编辑，相关定位能力会提示受限。

## 跨预设复制

桌面并排显示只读来源 A 和可编辑目标 B，默认用摘要阅读。选择完整条目，可搜索文本、查看关联、决定是否一起复制依赖；不自动复制所有同变量候选。

在 B 正文条目间的插入位置点击或拖入，按真实条目 ID 插入，保持来源相对顺序；过滤搜索不会改变插入锚点。复制保留角色、原文、注入和触发等原生及未知属性，生成新 identifier，保留关闭状态；未放置来源复制后保持关闭。系统 marker 和配置不作为普通文本复制，不复制来源方案或分组，不自动重命名变量或覆盖同名条目。

复制页提示缺失读写端和可能的变量覆盖，支持撤销最近一次粘贴。B 保存后才提交；A 不变。读取或保存非当前预设不会切换当前聊天的活动预设，保存当前预设会同步运行状态。

## 手机交互

适配窄屏和触屏横屏。正文、详情与阅读设置分页面，返回优先回到正文；复用桌面条目、分组、方案组件。

- 点击正文只选择，底部按钮打开详情；多选控件与系统文字选择分开，不因长按强制跳页。
- 复制用左右箭头切换 A／B，持续显示角色、名称与已选数量；保留各自滚动、搜索和选择状态，不用正文横滑触发换页。
- 已选条目可集中审阅和移除。目标正文点选位置后，底部显示位置与“粘贴 N 项”确认，防止误触直接插入。
- 分组提供移动到、上移／下移与移出操作，不依赖拖拽。
- 输入字号、点击区域、可视视口和安全区已适配；键盘与真实设备表现仍需验证。

## 保存与撤销

正文、开关、分组及复制修改先进入工作台草稿，不影响实际生成。保存检查读取基线；外部变化或保存失败保留草稿，不静默覆盖。该检查针对本浏览器所见状态，不是跨设备服务器原子锁。

“撤销全部未保存修改”重新读取已保存版本；已独立保存的方案不撤销。“撤销这次粘贴”仅移除最近粘贴内容。返回快速面板前须处理未保存草稿，避免两个来源同时编辑；收起工作台保留当前会话草稿。刷新／离开有提示，但没有刷新后的持久草稿恢复。

## 已知缺口与后续范围

- 手机缺少桌面全局诊断列表的完整入口；条目诊断、通用范围说明和无法定位条目提示仍可见。
- 真实 ST 当前／非当前预设保存、失败及外部修改等端到端人工验收尚未完成；物理 iOS／Android 键盘、长按和安全区尚未验证。
- 方案重命名与覆盖更新、宏关系分组建议、逐行修改前后对照尚未实现。当前可另存、预览、应用和删除方案，并查看改动摘要。
- 文档目录导航已按用户决定暂缓；不依赖个人预设的标题命名惯例来自动推断章节。
- 复杂嵌套变量表达式、简写变量操作、inc/dec/delete 等不在当前可靠支持范围。完整模型请求和第三方引擎不在本版范围。
